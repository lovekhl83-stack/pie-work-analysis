# PIE - Powernet Industrial Engineering

## 설치 방법 (Installation)

### 방법 1: setup.bat 실행 (권장)
1. 이 폴더에서 `setup.bat` 더블클릭
2. Windows 차단 경고가 뜨면:
   - "추가 정보" 클릭 → "실행" 클릭
   - 또는: setup.bat 우클릭 → 속성 → "차단 해제" 체크 → 확인
3. 설치 완료 후 바탕화면의 `PIE.html` 실행

### 방법 2: install.vbs 실행 (대안)
1. `install.vbs` 더블클릭
2. 성공 메시지 확인 후 바탕화면의 `PIE.html` 실행

### 방법 3: 직접 복사
1. `PIE.html` 파일을 바탕화면에 직접 복사
2. 더블클릭하여 실행
